  File: `dist/aws-icons-mermaid.json`.

  its full text is retained in `AWS-ICONS-LICENSE.txt`. The downloaded JSON
  retains its original `info` attribution. Icon shapes/colors are not edited;
  the adapter only maps lookup names and wraps original SVG bodies for display.
  AWS reference: https://aws.amazon.com/architecture/icons/.

The AWS data was checksum-verified before vendoring. Lookup aliases and the pack prefix were added; three names containing punctuation
were normalized to hyphens for Merman’s Iconify identifier grammar. SVG artwork
was not changed. Repeated, unreferenced XML ID attributes in the Snowball Edge
icon were removed to satisfy Merman’s XML validator; paths, colors and rendering
remain unchanged.
