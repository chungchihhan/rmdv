# rmdv v0.9.0 — rounder tables, calmer reading, safer Quick Slots

> Published 2026-10-16.
>
> Source: `main@2a78558`; tag: `v0.9.0`.
> Release: <https://github.com/minchenlee/rmdv/releases/tag/v0.9.0>
> (Release workflow run 38896180016).

rmdv v0.9.0 makes documents nicer to read. Tables get a softer, rounded look.
Body text, headings, and spacing follow the rhythm of Notion, and you can
change the line spacing yourself. Quick Slots get a new shortcut for saving a
file, and rmdv now asks before it replaces a file that is already in a slot.

## Highlights

### Rounded tables

- Tables have a rounded outer border, a lightly shaded header row, and thin
  lines between rows. The vertical column lines are gone.
- Cells have more room. The colors come from your theme, so tables look right
  in every built-in theme, light or dark.

### Notion-like reading typography

- Body text is 16 px with a line height of about 1.5. Paragraphs sit closer
  together, and headings get more space above them, so sections are easier to
  spot.
- The reading column is a little narrower (720 px), which keeps long lines
  comfortable to read.
- **Line spacing** is a new setting (`⌘,` → Appearance → Line spacing). Pick
  **Compact**, **Default**, or **Relaxed**. rmdv saves your choice.
- A custom theme can set `line_height`. This value used to be ignored; now it
  takes effect.

### Quick Slots: assign with `⌥⌘1`–`⌥⌘9`

- Press `⌥⌘1`–`⌥⌘9` to put the current file in that slot. `⌘1`–`⌘9` still jump
  to a slot.
- If the slot already holds a file, rmdv asks "Replace Quick Slot N?" first.
  Press `Esc` to cancel or `Enter` to replace.
- `⌘N` no longer adds a file to a slot. It has no other job in rmdv.
- The shortcut sheet (`⌘/`) lists the new shortcut, and it now shows every row.

## Known limitations

- A very wide table scrolls sideways, and its right-hand rounded corner shows
  only when you scroll to the right edge.
- After `rmdv goto`, a table row clipped at the top of the viewport can render
  without text (`MDV-038`).
- Windows builds remain best-effort and have no PDF extraction.
