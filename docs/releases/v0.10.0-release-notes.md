# rmdv v0.10.0 — select and copy text, and better Chinese reading

> Prepared 2026-10-17. Source: `main` after `d53f0a3`. Not yet tagged when this file was written; see the release page for the final state.

You can now select text in rmdv and copy it. Chinese text reads better too.

## Highlights

### Select and copy
- Drag over text in a document to select it. Press ⌘C to copy.
- One drag can cross many paragraphs, headings, lists, and quotes. Everything in between is copied.
- Double-click selects a word. Triple-click selects a line.
- ⌘A selects the whole document. ⌘C copies all of it.
- ⌘C also works when your input method is Zhuyin or another non-Latin one.
- Text in the JSON/YAML data view can be selected as well.

### Better Chinese reading
- Chinese text now uses a bundled Noto Sans TC font, so it looks the same on every Mac.
- Chinese lines have more room between them.
- Full-width punctuation is squeezed to look natural. Copying it gives you the original characters.

## Known limits
- You cannot drag past the window edge to select text that is off screen.
- Selecting across a very long scroll can copy more than you see at the far ends.
- After a double or triple click, dragging into another block selects by character.
- Shift + click to extend a selection works inside one block only.
