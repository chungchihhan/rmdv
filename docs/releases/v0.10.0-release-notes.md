## What's New in v0.10.0

You can now select text in rmdv and copy it, and Chinese text reads better.

### ✨ New Features

- **Select and copy text** (MDV-040): Drag over text to select it, then press ⌘C. Double-click selects a word. Triple-click selects a line. This works in the reader and in the JSON/YAML data view.
- **One drag across many blocks** (MDV-040): A single drag can cross paragraphs, headings, lists, and quotes. Everything between the start and the end is copied, and the selection is highlighted as you drag.
- **Select the whole document** (MDV-040): ⌘A selects the whole document, including folded sections. ⌘C copies all of it.
- **⌘C works with any input method** (MDV-040): Copy now works when the input source is Zhuyin or another non-Latin one.
- **Better Chinese reading** (MDV-040): Chinese text uses a bundled Noto Sans TC font, so it looks the same on every Mac. CJK lines are taller. Full-width punctuation is squeezed to look natural, and copying it gives you the original characters.

### 🐛 Bug Fixes

- **Block quote rule** (MDV-040): The left rule of a block quote is now a thin layer, not a shadow. It looks the same as before in the app, and no longer fills the whole quote in headless screenshots.

### ⚠️ Known Limits

- You cannot drag past the window edge to select text that is off screen. There is no auto-scroll yet.
- If an end of the selection scrolls out of view, ⌘C copies the whole block at that end.
- After a double-click or triple-click, dragging into another block selects by character.
- Shift + click extends a selection inside one block only.
- The app is about 4 MB larger because the Chinese font is built in.

### 📦 Installation

**Download** (checksums are in `SHA256SUMS`):
- **macOS**: `.dmg` (Apple silicon: `aarch64`; Intel: `x86_64`)
- **Linux**: `.AppImage`
- **Windows**: `rmdv_0.10.0_x64-setup.exe` or `rmdv.exe`

The in-app updater offers this version to existing macOS and Linux installs.
